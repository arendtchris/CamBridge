ESP32-C3

GoPro Bridge BLE

Firmware aus dem Browser flashen (Chrome / Edge). GoPro-Status ins Betaflight-OSD über MSP.

Install

  1. Daten-USB-Kabel verwenden, Serial Monitor / andere Tools am Port schließen.
  2. ESP32 direkt am PC anschließen (nicht nur über den Flight Controller).
  3. Connect klicken, Port wählen, Dialog folgen.
  4. Erster Flash kann Bonds und NVS-Einstellungen löschen.
Web Serial ist in diesem Browser nicht verfügbar. Desktop Chrome oder Edge über HTTPS nutzen. Keine Berechtigung – Seite muss über HTTPS oder localhost laufen.

Boot-Modus nötig? BOOT halten, RESET drücken, BOOT loslassen, dann erneut Connect.

Hardware-Nummer auslesen

Liest Chip-Typ und MAC-Adresse (eindeutige Hardware-ID) über den ROM-Bootloader. Gerät wird kurz zurückgesetzt.

  1. Gleiches Daten-USB-Kabel, Port freigeben (kein Install/Serial Monitor parallel).
  2. Bei Bedarf Boot-Modus: BOOT halten → RESET → BOOT loslassen.
  3. Hardware-ID lesen klicken und den ESP-Port wählen.
